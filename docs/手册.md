## 3. 完整契约清单

**gRPC `erp.inventory.v1.InventoryService`**（9 个 rpc，见 `contracts/erp/inventory/v1/inventory.proto`）：

| rpc | 类型 | 暴露到 REST？ |
|---|---|---|
| `Reserve` / `CancelReservation` / `ConfirmIssue` | 写，TCC 三件套 | ❌ 组件间协议，不是人类操作 |
| `GetReservationStatus` | 读 | ❌ 同上；区分 `NOT_FOUND` 与 `CANCELLED`（防"薛定谔的超时"） |
| `Receive` / `Adjust` | 写 | ✅ `/erp/inventory/movements/receive`、`/movements/adjust` |
| `GetBalance` | 读 | ✅ `/erp/inventory/balances` |
| `BatchGetBalance` | 读 | ❌ 只给组件间 gRPC 客户端防 N+1 用 |
| `ListMovements` | 读，游标分页 | ✅ `/erp/inventory/movements` |

**发布事件：** `erp.inventory.adjusted.v1`（`Receive`/`ConfirmIssue`/`Adjust` 都发）、`erp.inventory.transferred.v1`（占位，阶段二不实现）。
**消费事件：** `mdm.product.created.v1` / `.updated.v1`（只取 `tracking_type` 维护摘要副本）。

详细字段与判据见设计计划 `docs/design/erp-inventory.md` §3、§4——那份是真相源，这里是速查表。
